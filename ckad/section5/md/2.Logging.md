# Logging

## 1. Docker에서의 로깅

#### 로그 즉시 출력
```bash
docker run kodekloud/event-simulator

2018-10-06 15:57:15 - USER1 logged in
2018-10-06 15:57:16 - USER2 logged out
...
```

컨테이너를 foreground에서 실행하면 로그가 콘솔에 바로 출력된다.
컨테이너가 표준 출력(stdout)으로 내보내는 로그가 콘솔에 바로 표시된다.

#### 분리(detached)모드와 `docker logs`
`-d`옵션을 사용해 컨테이너를 백그라운드(분리 모드)에서 실행하면 로그가 콘솔에 바로 표시되지 않는다
```bash
docker run -d kodekloud/event-simulator
```

이 때는 **컨테이너 ID**와 함께 `docker logs`명령으로 나중에 로그를 확인할 수 있다.

```bash
docker logs <container_id>
docker logs -f <container_id> # -f (follow): 실시간 추적
```

## 2. Kubernetes에서의 로깅
Kubernetes에서도 개념은 동일하다. 위의 도커 이미지를 Pod로 작성해 생성할 수 있다.

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: event-simulator-pod
spec:
  containers:
    - name: event-simulator
      image: kodekloud/event-simulator
```

```bash
kubectl create -f event-simulator-pod.yaml
```

pod가 실행되면 `kubectl logs`명령에 Pod 이름을 붙여 볼 수 있다.
```bash
kubectl logs -f event-simulator-pod

2018-10-06 15:57:15,937 - root - INFO - USER1 logged in
2018-10-06 15:57:16,943 - root - INFO - USER2 logged out
2018-10-06 15:57:17,944 - root - INFO - USER2 is viewing page2
...
```

## 3. multi container pod의 경우
하나의 pod 안에 여러 컨테이너를 실행할 수 있다.

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: event-simulator-pod
spec:
  containers:
    - name: event-simulator
      image: kodekloud/event-simulator
    - name: image-processor
      image: image-processor
```

이 상태에서 pod에 log명령어를 바로 날리면 kubernetes에서는 어떤 컨테이너에 대한 로그를 날려줘야하는지 명시해줘야한다.

```bash
kubectl logs -f event-simulator-pod event-simulator
```

---
#### 정리

- **`kubectl logs <pod-name>`** : Pod의 로그를 확인하는 기본 명령.
- **`-f` (follow)** : 로그를 실시간으로 스트리밍. (Docker의 `docker logs -f`와 동일한 개념)
- **`-d` (detached, Docker)** : 백그라운드 실행 시 콘솔에 로그가 안 보이며, `docker logs <id>`로 확인.
- **멀티 컨테이너 Pod에서는 컨테이너 이름을 반드시 명시**해야 함
  → `kubectl logs -f <pod-name> <container-name>` (생략 시 에러 발생).
- 컨테이너 로그의 원천은 애플리케이션의 **표준 출력(stdout/stderr)** 이다.
- 시험 팁: 자주 쓰는 추가 옵션
    - `--previous` : 재시작 이전(이전 인스턴스) 컨테이너의 로그 확인 (CrashLoop 디버깅에 유용).
    - `--tail=N` : 마지막 N줄만 출력.
    - `-c <container-name>` : `<pod> <container>` 대신 `-c` 플래그로도 컨테이너 지정 가능.
